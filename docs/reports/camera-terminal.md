# Camera Terminal (CAMTERM)

1. Base upgrade `camera` (BASE tab, homebase.js): L1 25 elixir, L2 40, one purchase per base through the normal Elixir Screen row. Using it costs 2 elixir to start a feed and then 1 per 15 s (L2: 1 per 20 s); L1 feed lasts 2 min, L2 5 min and adds the Vault. Whole tree is now 505 (balance test bound raised to 520).
2. Rules and the browser overlay live in `camterm.js` (UMD, pure rules plus `createCamUI`); server glue is one tagged `CAMTERM` block in server.js (`camMsg`, `camTick`, `camView`) with three one-line hooks (message route, `homeMsg` branch, `camTick` in `elixirTick`). Wire: `{cam:{open:1|room:'7'|close:1}}` in, `{cam:frame|null}` and `{camRes}` out.
3. View is a top-down schematic from server data, not a second render target: other rooms are culled client-side and their goblins only arrive at 5 Hz, so a 3D feed would need extra scene work and would be wrong; the schematic costs one 480x360 canvas redraw per frame and the server filter is the privacy boundary (the client cannot draw what it never received).
4. Fairness: frames go only to the session owner, max 4 per second (identical frames skipped, 1 s heartbeat), caps 16 goblins / 12 foes / 12 piles, `homeRate` 8 msgs/s plus the socket token bucket. Only arena cells (never homes, never vault below L2); sent fields are id, name, position (0.1 m), health in 5% steps, loot pile counts, door open/closed, crown claimant. No items, gold, vault picks. A tree room whose goblin holds the Hollow Oak shows "SIGNAL LOST" with no occupants.
5. Round 1 (home only) refuses ("live in round 2", same as sends); dead in sudden death and in the showdown; owner must stay within 2.5 m of the terminal and alive in his live home, or the feed ends. Death kills the home and the upgrade.
6. Optional "camera spotted": occupants whose home has an Alarm get a nameless toast, once per 20 s each. Bots never use it.
7. Art: `rooms5art-home.js` `upg.camera` (pedestal, monitor with an emissive green face, dome with red lens; merged, no lights), shown at `setUpgrade('camera', lv)`; position `WORLD.HOME_LAYOUT.cam`; E prompt kind `c` ("Use the Camera Terminal", only shown when owned). Not a collision solid (kept out of HOME_SOLIDS to leave the art/world wiring test alone).
8. Sounds reuse `panel`, `uiClick`, `deny`. Codex: the upgrade rows are generated from `HB.UPGRADES`; a "Camera Terminal" row was added to the home facts in tools/gameinfo.js and docs/game-info.html regenerated.
9. Tests: `tests/camterm.test.js` (pure rules, frame privacy, headless art, live server: purchase, refused before owned and in round 1 and for non-owners, frames only after open, rate cap, junk and flood, vault tier, homes refused, leaving the terminal, meter end, camera spotted). `npm test`: 68 files pass (no `test:affected` script exists in this tree).
10. Not verified: nothing was looked at in a real browser (overlay layout, canvas drawing, prop look and placement against neighbouring props, E prompt aim), the Hollow Oak "signal lost" path live (pure frame test only), sudden death and showdown live (gate unit tested only), and tier II tab text width in the Elixir Screen.
