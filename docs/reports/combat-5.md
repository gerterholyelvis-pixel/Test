# Combat 5: the rules of a fight

Code: `combat5.js` (pure, shared: stamina, chain, whiff, guard numbers), items.js `COMBAT5` (the ONE tunable table: STA, COMBO, GUARD, per family FAM, RULES, the COUNTER rows and Codex TEXT), server.js `COMBAT5` block (+ small hooks in `attack`, `c4Start`, `c4Done`, `c4Apply`, `c4Stagger`, `dash`, `windUp`, the message handler, `fight6`), game.js `COMBAT5` block (+ hooks in combatSwing, the heavy release, dash, `c4Msg`, `combatMsg`).

- **Guard / parry**: hold X (or the right mouse button with a weapon that has no heavy blow). Server-side `target.guard` through combat4's guard hook. Blocks cut damage by family (sword to 40 %, dagger 65 %, hammer 60 %), 75 degree front cone, slower walk. A guard raised in the parry window (200-280 ms + 60 ms latency slack, from the raise) parries: no damage, the attacker reels 520 ms, the parrier regains stamina and gets a x1.25 riposte. No parry against shots, hammers, heavy blows, or with hammer/whip/wand. Re-raise pause 450 ms (tap-spam proof).
- **Stamina** (100, regen 26/s after 650 ms): swings (~13/s of swinging for every family), dash 18, heavy +22, guard raise 6 and hold 7/s, blocks 0.8 x damage x the attacker's drain (axe 1.5, hammer 2). Never a wall: at 0 a swing still happens (slower x1.25, weaker x0.85), a dash / guard / wind-up only needs a little. A guard with no stamina breaks (cue brk, 85 % of the blow, short stagger).
- **Combo / whiff**: a landed blow makes the next swing recover 0.8 x (dagger 0.72), the third is a finisher (+20 %, 160 ms stagger, 1.2 x recovery); a whiff costs +0.3 x cd; blocked / parried breaks the chain. The client runs the same pure functions (swr carries why p/b), so its cooldown matches the server's.
- **Counter table**: spear +25 % on a goblin that closed in, sweeping blows +15 % on daggers (+10 % whips), axe/hammer drain blockers, bows cannot guard. Cues: BLOCK / PARRY! / GUARD BREAK / FINISHER floats, clang + hit-stop, `!` over a heavy wind-up and a finisher swing, a stamina bar under the crosshair, a steel glow on other goblins' guards, a blue edge for mine.
- **Bots** (`guard6`, one call in `fight6`): per foe swing a level-scaled roll to block (timed 70-230 ms before contact, so some parry) or to hold a block stance; winded bots step back and breathe. Stamina, combos and whiffs apply to them through `attack()`.
- **Protocol** (all optional): `{grd:1|0}` up, `grd/off/k` and `sta:[v,holdMs]` down, `fin` on swing/hit, `brk`, swr why `p`/`b`.
- **Balance** (tools/balsim.js models stamina, chains and whiffs now; `{c5:false}` = old): start-kit goblin win rates 0.46-0.56 (before 0.47-0.53); weapon / armour ladders still pass (hand crossbow cost lowered to keep ranged level). duelsim (tools/duelsim.js, spacing follows the whiff rule): reg 96 / 100 / 96 / 89 / 100 %, phantom 0 / 0 / 15 / 29 / 0 % (0, 100, 200, a200v20, a20v200 ms), no regression vs combat-4.
- **Tests**: `tests/combat5.test.js` (pure rules, table coverage, block, parry + riposte, guard break, winded, combo + finisher, whiff, dagger weakness, bot guards); combat, combat4, balance3, climb unchanged green (combat4 cleave-share assertion is a pre-existing flake on goblin type perks).
