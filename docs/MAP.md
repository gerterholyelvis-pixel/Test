# Repo map

How to use: find the tag or file below, then `Grep "<TAG>-BEGIN" <file>` for the current line and Read only that range
(`offset` / `limit`). The tables after "Generated" are rebuilt by `npm run map`; `node tools/mapgen.js --print PANEL` prints fresh
numbers for one tag without writing anything.

## Who loads what
- **Browser**: `index.html` (line ~623) loads classic scripts audio, feel, vfx, hud5, world, items, save, icons, homebase, homeui,
  act5ui; then a module script imports `three` (importmap), `itemart.js`, `rooms5art-{home,trees-a,trees-b,vault}.js` (as
  `window.GK5ART`), `client/ui/tags.js`, `game.js`, `menu.js`. Served files: `CLIENT_JS` in server.js (root files) and anything under
  `client/**.js`.
- **Server**: `server.js` requires world, items, doorguard, botnav, botgoals, activity, vb5, vault5, homebase, elixir, act5
  (act5 pulls rooms5-trees). Tests spawn `node server.js`, so it stays the entry point.
- **Shared (UMD, both sides)**: world.js (geometry, rooms, doors), items.js (item tables, SPEED, WEAPON_TUNE), activity.js, elixir.js,
  homebase.js, act5ui.js, vb5.js. Change these with a test in the fast tier.
